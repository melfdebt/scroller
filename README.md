# scroller
# Platformer — лабораторная работа 2

## О проекте

Проект представляет собой прототип динамичного платформера на **Godot Engine 4.7 + C# (.NET)**. Игрок может перемещаться по горизонтали, прыгать на платформы с разной высотой, стрелять по врагам и получать урон от опасных объектов. Мир организован как скроллер: платформы, враги и препятствия появляются справа и движутся влево.

## Управление

| Действие | Управление |
|---|---|
| Движение влево | `A` |
| Движение вправо | `D` |
| Прыжок | `Space` |
| Стрельба | Левая кнопка мыши |

Высота прыжка переменная: удерживание `Space` во время подъёма уменьшает действующую гравитацию на ограниченное время. Параметры движения, прыжка и здоровья вынесены в экспортируемые поля игрока.

## Основные механики

### Игрок (`Player`)

`Player.cs` реализует горизонтальное движение, гравитацию, прыжок с переменной высотой, стрельбу и систему здоровья. Параметры скорости, гравитации, импульса прыжка, времени удерживания прыжка и максимального здоровья доступны в Inspector.

### Пули (`Bullet`)

Пуля использует `CharacterBody2D` и движется через `MoveAndSlide()`. Скорость задаётся через `Velocity`. Метод `SetDamage()` задаёт урон, а `SetFriendly()` различает дружеские и вражеские пули. Пули игрока наносят урон врагам; пули дракона предназначены для нанесения урона игроку.

### Спавн и скроллинг (`Main` и `MovingObject`)

`Main.cs` хранит массивы `PackedScene` для платформ, врагов и препятствий. Через заданные интервалы времени случайно выбирается сцена и создаётся экземпляр:
- платформы — по `PlatformSpawnInterval` (по умолчанию 2 секунды);
- враги — по `EnemySpawnInterval` (по умолчанию 3 секунды);
- препятствия — по `ObstacleSpawnInterval` (по умолчанию 2,5 секунды).

Массивы сцен настроены в Inspector корневого узла главной сцены. 

`MovingObject` — базовый класс движущихся объектов. Он реализует перемещение с помощью виртуального метода `Move()`, предоставляет виртуальный метод `GetSpawnPosition()` и удаляет объект после выхода за экран. Конкретные классы могут переопределять движение и координаты появления.

## Иерархия классов

В проекте используется наследование и полиморфизм: базовые классы задают общее поведение, а наследники переопределяют `Move()` и/или `GetSpawnPosition()` либо добавляют собственные механики.

```text
MovingObject (abstract, Area2D)
├── DamagingObject (abstract)
│   ├── Enemy (abstract)
│   │   ├── GroundEnemy (abstract)
│   │   │   ├── Zombie
│   │   │   └── Warg
│   │   └── FlyingEnemy (abstract)
│   │       ├── Bat
│   │       └── Dragon
│   └── Obsatcle (abstract; имя класса в исходном коде)
│       ├── GroundObstacle (abstract)
│       │   ├── Rock
│       │   └── Spike
│       └── FlyingObstacle (abstract)
│           └── Saw
└── Platform (abstract)
    ├── VerticalPlatform
    └── FloatingPlatform
```

### Базовые классы

| Класс | Назначение |
|---|---|
| `MovingObject` | Общая логика движения, виртуальные `Move()` и `GetSpawnPosition()`, удаление после выхода за экран. |
| `DamagingObject` | Общая обработка контакта с игроком и нанесение контактного урона. |
| `Enemy` | Здоровье врагов, получение урона и удаление при нулевом здоровье. |
| `GroundEnemy` | Базовые свойства наземных врагов, скорость движения и ссылка на игрока из группы `player`. |
| `FlyingEnemy` | Общая база летающих врагов, скорость полёта и стандартная точка появления. |
| `Obsatcle` | Общий класс препятствий; имя написано именно так в текущем исходном коде. |
| `GroundObstacle` | База наземных препятствий. |
| `FlyingObstacle` | База летающих препятствий, реализует движение влево. |
| `Platform` | Базовый класс платформ. |

### Конкретные объекты

| Класс | Поведение |
|---|---|
| `Zombie` | Движется влево и периодически делает рывок в сторону игрока. |
| `Warg` | Изменяет горизонтальное направление движения, чтобы преследовать игрока. |
| `Bat` | Летит по синусоидальной траектории. |
| `Dragon` | Летит влево и периодически стреляет в направлении игрока. |
| `Rock` | Наземное препятствие с базовым поведением `GroundObstacle`. |
| `Spike` | Периодически выдвигается и убирается; контактная опасность включается только в выдвинутом состоянии. |
| `Saw` | Летит влево по синусоидальной траектории. |
| `VerticalPlatform` | Платформа с заданными координатами появления по горизонтали и вертикали. |
| `FloatingPlatform` | Платформа, для которой вертикальная координата появления выбирается случайно в заданном диапазоне. |
